# 雨课堂通知 · 课简扩展组件

[English](README_en.md)

登录自己的雨课堂账号后，老师发布的**作业、课件、章节测试、考试和课程公告**由 [课简](https://github.com/cursimple/cursimple-app) 来提醒：

- **新内容通知**：老师新发了作业、课件、考试或公告，推一条通知
- **截止前提醒**：作业、考试截止前 N 小时再提醒一次（1 / 3 / 6 / 12 / 24 / 48 小时可选）
- **组件自带月历**：界面随组件包安装，整月显示，点击日期查看当天内容；往期公告用灰色弱化
- **写进课表事务**（可选）：还没做完的作业直接出现在课表上，做完或删掉后自动撤掉

组件和课简本体是解耦的：组件包负责登录、数据获取及所有业务页面；课简提供通用容器、主题颜色、通知、存储和课表接口。

组件还自带 `ui/feed.html` 页面。课简只提供通用容器、数据和同步桥，月历与公告详情由组件自己绘制；以后替换这个页面只需要更新组件 ZIP。

组件自带 `ui/login.html`（登录）和 `ui/settings.html`（设置）两个页面，登录协议（短信验证码、腾讯安全验证）也全在组件里。课简不解析任何雨课堂接口，只提供通用的 Cookie、网络和存储能力。

内容的类型也由组件定义：清单里 `feedTypes` 的每一项声明 `kind` 为 `task`（待完成，有明确截止时会算逾期，也能写进课表）或 `notice`（读完即止）。课简不认具体类型名，换个平台或改类型 id 都不用动课简。

## 安装

当前本地版本：**1.3.8**。

本地版本已移除微信扫码登录，登录页直接使用手机号短信验证码。已有登录会话继续使用；配合上一版 API 11 APK，导入新版组件即可。

需要支持扩展组件（插件接口版本 11）的课简；更老的版本会提示「接口版本太新」而拒绝安装。

1. 在 [Releases](https://github.com/cursimple/YuKeTang_notice_plugin/releases) 下载 `yuketang-notice-vX.Y.Z.zip`
2. 课简 → 侧边栏「插件」→「组件」标签页 →「导入 ZIP」，选中这个包
3. 在已安装组件里点「雨课堂通知」→「打开组件」，在主页登录

## 登录

点「登录」会在课简内打开手机端登录面板，使用手机号短信验证码。短信发码前先完成官方腾讯安全验证。账号校验通过后显示“连接成功”，可进入课堂页面或调整设置；失败显示具体原因，支持重新检查登录结果。

- 短信验证码直接交给雨课堂登录接口；课简不保存手机号和验证码，只保存登录后的 Cookie，用来在后台同步
- 登录过期时课简会发一条通知，点进去重新登录即可
- 账号头像优先读取个人资料接口，兼容网页资料中的头像字段；HTTP 头像地址改用 HTTPS。切换账号会重新读取，资料接口失败时保留已验证的登录状态。
- 「退出登录」「移除组件」会作废这些 Cookie，并删掉已同步的内容

自学课件归入「作业」，待办、小组件与新内容提醒共用现有设置。每次同步读取官方阅读完成状态，活动和章节中的同一资源只显示一次；没有明确截止时间的课件不套用课程结课日期。课件详情可直接进入阅读页，支持翻页、页码跳转、双指缩放和失败重试，返回保留详情。完整支持的页面使用原始图片与文字按官方坐标还原，不再放大 128 像素封面；不支持的版式或高清加载失败保留整页预览并提示重试；详情与预览页都提供「前往雨课堂」，提示用户到雨课堂查看并完成学习；完成情况在下次同步时按官方记录更新。已用真实登录会话只读核对课程活动、成绩与课件详情，并验证真实 28 页课件的读取与翻页；手机通知送达仍需设备验证。


账号校验和保存完成后自动进入课堂，并由配套 APK 同步一次。再次打开登录页会恢复已保存账号；课堂页面加载失败时，只需重试打开页面。

## 界面

未登录或登录过期时，专属页面只显示登录引导。登录后可切换月历和列表；点击日期查看当天条目，点条目阅读正文、图片和附件。设置首页收纳为四个入口，详细选项在独立面板中显示。常规手机尺寸下主页面保持一屏；长列表、正文、大字体和键盘弹出时允许必要滚动。配色跟随宿主浅色／深色主题。

## 用到的接口

同步内容使用雨课堂网页版的读取接口；已读操作仅在用户点确认后调用官网流程并回查结果，登录提交用户主动完成的验证与登录操作：

| 用途 | 接口 |
| --- | --- |
| 短信登录 | `POST /pc/login/send_sms_login_code/` → `POST /pc/login/verify_pwd_login/` |
| 课程列表 | `GET /v2/api/web/courses/list?identity=2` |
| 登录校验与账号 | `GET /api/v3/user/basic-info` |
| 账号头像 | `GET /mobile-app/api/user/profile`，回退到 `GET /api/web_lesson/user_info/` |
| 作业列表 | `GET /c27/online_courseware/course/classroom/{cid}/0/sku_list/` → `…/schedule/score_detail/single/{sku}/0/` |
| 作业截止时间 | `GET /mooc-api/v1/lms/learn/leaf_info/{cid}/{leaf}/` |
| 自学课件 | `GET /v2/api/web/logs/learn/{cid}`（type 2），结合成绩叶子和 `leaf_info` 合并章节课件 |
| 课件阅读 | `GET /v2/api/web/cards/detlist/{cards_id}?classroom_id={cid}`，读取官方页面图片 |
| 考试 | `GET /v2/api/web/logs/learn/{cid}`（type 5）+ `GET /v/exam/cover` |
| 公告 | `GET /v/discussion/v2/announcements/?cid={cid}&type=9` |
| 系统消息 | `GET /c27/online_courseware/ykt/system_message/?client_type=2` |

截止时间和交卷状态会缓存在组件自己的存储里，已完成、已截止的条目不再重复请求。

### 登录续期

雨课堂没有 `refresh_token` 之类的续期接口，续期是**被动**的：普通响应的 `Set-Auth` 头会下发新的 bearer token，`Set-Cookie` 会顺带刷新 `csrftoken` / `sessionid`。官方 App 的拦截器就是每收到一个响应就把这两样读回来、下一个请求直接复用，所以它从来不“调接口续期”。

组件采用同一套机制（`main.js` 的 `createSessionTokens` / `pageSession`）：

- `getJson`、`sessionFetch`、课件读取三处请求都会 `absorbResponse`，把 `Set-Auth` 和 `Set-Cookie` 收进来；
- 后续请求的 `Authorization` / `X-CSRFToken` 以轮换后的值为准，调用方传入的旧值会被覆盖；
- **轮换结果会持久化**：同步是每分钟一次的全新 JS 上下文，只存内存等于每次从头开始。入口包写 `ctx.state`，自有页面写 `localStorage`；
- 持久化副本带站点身份，换站点时旧凭据立即作废，不会把 A 校的 token 发到 B 校；
- Cookie 仍归宿主的 cookie jar 所有（脚本写一份同名 cookie 反而会遮蔽 HttpOnly 的那个），这里存的值只用来在 jar 被问之前拼出正确的 `X-CSRFToken`；
- 真失效时仍是原来的行为：`401` / `UNAUTHENTICATED` → `loginRequired` → 提醒重新登录，同时**清掉**持久化副本，避免下次拿死 token 重试。

## 内容操作

公告详情右上角提供「已读」，确认后读取官网公告详情并回查公告列表的 `is_read`。官网 `/v/discussion/v2/notice/read/info/` 是教师查看阅读名单的 GET 接口，不用它写入已读。系统消息使用 `/api/v3/message/notice/read`，同样回查状态。失败保持未读并显示错误，不用本地已读集合冒充官方同步。

> 已读流程的成功、失败分支有单元测试覆盖，但**尚未用真实账号验证官网服务端的实际结果**；首次使用请到官网确认公告确实显示为已读。

内容详情可忽略或恢复，页面的「已忽略」入口不受正常页面日期范围限制。设置 → 通知与同步增加默认关闭的「自动忽略逾期任务」；忽略内容不参与待完成小组件或提醒，自动忽略开启时单条恢复仍有效。这些选择由通用宿主协议保存，雨课堂接口、ID 解析、业务页面均保留在此独立组件包。

## 桌面小组件

组件通过 `extension.widgets` 声明「雨课堂待办」。布局、文案、待办筛选和跳转均由组件包中的 `ui/widget.html`、`widget.css`、`widget.js` 与 `widget-model.js` 管理，软件通过 API 9 提供数据、渲染和桌面绑定接口。安装并启用本组件后才会出现对应小组件；卸载或停用后入口消失。支持简体中文、繁体中文和英文，自动适应桌面尺寸与字体大小；忽略的任务不显示，单条恢复后重新显示。

本地演示的附件预览使用 Mozilla PDF.js（Apache-2.0），提供真实的两页 PDF 示例和翻页、缩放、下载。依赖与示例位于开发脚本目录，不进入组件安装包。图片先显示缩略图，点击后查看完整图片。

组件的常用按钮图标采用 [Google Material Icons Rounded](https://github.com/google/material-design-icons)，Apache-2.0 许可随组件打包。按钮配色跟随课简主体主题。

本地 1.3.8：首次登录自动同步一次，进入课堂不中断。课件支持单击放大、双击还原、双指缩放、左右滑动翻页与横竖屏按钮；切换保留当前页码和缩放，退出恢复原有方向。已用真实 28 页课件数据核对全部版式，并在浏览器验证第 19 页的高清原图与文字。手机上的屏幕旋转和登录后同步仍需实机确认。

图片与课件预览的返回操作先关闭顶层预览器，保留组件和内容详情；普通页面与诊断页面一致。课件优先使用可用原图和支持的完整高清版式，保留签名及裁剪地址。高清失败后的重试会重新获取课件信息，避免一直使用已过期的图片地址；仅有低清封面的页面会明确提示。
